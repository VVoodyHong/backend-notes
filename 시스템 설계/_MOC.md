# 시스템 설계

아키텍처, 확장성, API 계약, 분산 데이터와 안정성 패턴을 다루는 노트 모음.

## 추천 읽기 순서

1. [[MSA와 모놀리식 비교]] → [[수평 확장과 무상태성]] → [[API Gateway]]
2. [[RESTful API 설계 원칙]] → [[페이지네이션 전략]] → [[에러 응답 표준화]] → [[API 버저닝 전략]]
3. [[데이터 일관성 모델]] → [[CQRS 패턴]] → [[멱등성 키 설계]] → [[분산 ID 생성]]
4. [[Rate Limiting 알고리즘]] → [[서킷 브레이커와 장애 격리]] → [[Bulkhead 패턴]] → [[우아한 성능 저하]]
5. [[분산 트레이싱]]을 읽고 인프라·Spring의 구현 노트로 이어간다.
